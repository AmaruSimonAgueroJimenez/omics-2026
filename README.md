# Ómicas y Big Data en Medicina Traslacional — DCIM 2026

Repositorio oficial del electivo **Ómicas y Big Data en Medicina Traslacional**, Doctorado en Ciencias e Innovación en Medicina (DCIM), Universidad del Desarrollo.

## Descripción del curso

Curso de 14 semanas orientado a comprender los fundamentos de las técnicas experimentales que generan grandes volúmenes de datos ómicos y desarrollar habilidades prácticas para su manejo, análisis y aplicación en problemas de medicina traslacional.

## Cómo usar este repositorio

### Si eres estudiante del curso:

1. **Fork** este repositorio a tu cuenta personal de GitHub.
2. **Clona** tu fork a tu computador.
3. Crea tu carpeta en `estudiantes/tu-nombre-apellido/`.
4. Sube tus tareas mediante **Pull Requests** al repositorio original.

Instrucciones detalladas en [`clases/clase-03/guia-git-handson.md`](clases/clase-03/guia-git-handson.md).
